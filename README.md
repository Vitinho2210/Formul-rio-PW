# 🧮 Calculadora de IMC

Projeto desenvolvido com HTML, CSS e JavaScript para calcular o Índice de Massa Corporal (IMC) a partir dos dados informados pelo usuário.

---

## 📌 Sobre o projeto

A **Calculadora de IMC** é uma aplicação web desenvolvida como atividade acadêmica, com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end.

A aplicação permite que o usuário informe seu nome, peso e altura para realizar o cálculo do Índice de Massa Corporal, apresentando o resultado diretamente na página, sem a necessidade de recarregá-la.

O projeto também utiliza validações para garantir que os dados informados sejam válidos.

## 🚀 Funcionalidades

- [x] Formulário para inserção do nome do usuário.
- [x] Campo para informar o peso em quilogramas.
- [x] Campo para informar a altura em metros.
- [x] Cálculo automático do IMC.
- [x] Exibição do resultado com duas casas decimais.
- [x] Validação dos campos preenchidos.
- [x] Atualização do resultado sem recarregar a página.
- [x] Interface responsiva.

## 📐 Fórmula utilizada

O cálculo do Índice de Massa Corporal é realizado utilizando a seguinte fórmula:

**IMC = Peso / (Altura × Altura)**

**Exemplo:**

Considerando uma pessoa com:
- Peso: 65 kg
- Altura: 1,75 m

Resultado: **21,22**

## ⚙️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server.
5. Preencha os campos do formulário e clique em **Calcular IMC**.
